# Retroactive Birthright and Governance

## Summary

Retroactive Birthright TIME should give every verified human immediate governance voice.

This is essential to avoid a capital-first launch.

## Problem

If only liquid buyers and early workers can participate in governance, then TIME governance will begin captured by:

- capital;
- early insiders;
- exchanges;
- employers;
- speculators;
- foundations.

This contradicts the human-first principle.

## Governance Principle

```text
Every verified human's lived time should count in governance from the moment of verification.
```

## Status-Quo Allocation

Upon claim, governance-allocatable TIME may default to the status quo.

The Governance Agent then lets the user move TIME toward alternatives.

Default:

```text
retroactive_governance_TIME → status_quo_governance_objects
```

User action:

```text
move TIME → express preference
```

## Voting Weight

Recommended formula:

```text
votes = sqrt(governance_TIME_allocated)
```

This reduces the effect of extreme differences in age or accumulated TIME.

## Age and Governance Concerns

A one-TIME-per-day-since-birth rule means older humans receive more retroactive TIME.

This is coherent because they have lived more time.

But governance should consider whether raw lifetime TIME should translate directly into political weight.

Possible mitigations:

1. quadratic voting;
2. per-issue caps;
3. identity-based baseline votes;
4. separate liquid TIME from governance TIME;
5. recent-time weighting;
6. one-human-one-vote modules for certain decisions.

## Recommended Model

Use retroactive TIME for economic recognition, but use quadratic or capped weighting for governance.

```text
economic_recognition = days_alive
governance_weight = sqrt(TIME_allocated)
```

## Why This Works

It preserves the moral claim:

> all lived human days are recognized.

While preventing the governance problem:

> older or wealthier accounts should not dominate every decision linearly.

## Governance Agent Integration

The Governance Agent should show:

- total recognized TIME;
- liquid TIME;
- governance-allocatable TIME;
- default status-quo allocation;
- current allocations;
- alternative officials/laws/budgets/projects;
- effect of moving TIME.

## Public Narrative

> Your lifetime TIME gives you a voice from day one. Moving it is how you vote.
