# Parallel Society OS

## Definition

Parallel Society OS is the application-layer stack built on TIME Protocol.

It gives every verified human:

1. identity;
2. economic participation;
3. governance awareness;
4. local allocation;
5. private coordination;
6. reputation;
7. political voice.

## Five Layers

| Layer | Primitive | Function |
|---|---|---|
| Identity | Proof of humanity / World ID | one human, one account |
| Awareness | Governance Agent | who governs you and what laws apply |
| Economy | TIME Protocol | birthright + work-backed TIME |
| Governance | Shadow Democracy | allocate TIME to officials, laws, budgets, alternatives |
| Coordination | Waku / Logos / local feeds | communicate, organize, and allocate locally |

## Operating Loop

```text
Verify humanity
    ↓
Claim birthright TIME
    ↓
Governance Agent maps your jurisdiction
    ↓
TIME allocates to status quo
    ↓
User moves TIME to express preference
    ↓
User discovers local work and public goods
    ↓
Work/payment mints earned TIME + Work NFT
    ↓
Reputation and governance weight compound
    ↓
Parallel local institutions become visible
```

## Why This Matters

A parallel society cannot be created by manifesto.

It requires infrastructure:

- identity;
- money;
- records;
- governance;
- coordination;
- local economic loops.

TIME Protocol supplies the economy.

Governance Agent supplies awareness.

Waku/Logos supplies communication.

Reference applications supply lived proof.

## Design Objective

The user should be able to open one app and see:

- who governs them;
- what they can claim;
- what they can earn;
- what they can support;
- what they can oppose;
- where they can work;
- where their local alternatives are.

## Strategic Claim

> TIME Protocol is the economic layer of the Parallel Society OS.
