# Jurisdictional Pilots

## Summary

TIME Protocol can be piloted by jurisdictions, network states, cities, DAOs, communities, and micronations.

A jurisdictional pilot tests whether TIME can serve as:

- verified economic identity;
- work accounting system;
- governance layer;
- tax or fee routing layer;
- public-goods allocation mechanism;
- citizenship participation system.

## Candidate Pilot Types

### 1. Network State

Best for testing:

- census;
- governance alternatives;
- treasury;
- commons vaults;
- international membership;
- portable citizenship.

### 2. Micronation

Best for testing:

- citizenship onboarding;
- blockchain-native governance;
- low-bureaucracy fee systems;
- corporate infrastructure fees.

### 3. City or Municipality

Best for testing:

- local allocation;
- participatory budgeting;
- volunteer proof;
- small business support;
- public goods.

### 4. DAO

Best for testing:

- contributor payments;
- proof of work;
- reputation;
- governance allocation;
- budget distribution.

### 5. Nonprofit / Foundation

Best for testing:

- volunteer hours;
- public-good labor;
- grants;
- proof of service;
- UBI experiments.

## Liberland as Case Study

The Liberland blueprint shows how TIME could be used as:

- citizenship identity layer;
- economic layer;
- governance layer;
- clearinghouse;
- tax/fee routing mechanism;
- distinction between humans and corporations.

This should be documented as a case study even if the jurisdiction has not formally adopted it.

## Pilot Minimum Viable Scope

A credible pilot should launch with:

1. verified-human onboarding;
2. TIME claim interface;
3. work agreement and payment flow;
4. Work NFT receipt;
5. governance object registry;
6. TIME allocation dashboard;
7. local or jurisdictional public-goods pool;
8. privacy policy;
9. dispute process;
10. public metrics dashboard.

## Pilot Metrics

| Metric | Meaning |
|---|---|
| verified humans | real population |
| TIME claimed | participation floor |
| TIME earned | productive activity |
| Work NFTs minted | economic record |
| TIME allocated | governance engagement |
| local transactions | circular economy |
| public goods funded | civic usefulness |
| disputes resolved | institutional maturity |
| corporate fees routed | treasury viability |

## Strategic Principle

Do not start with national replacement.

Start with useful jurisdictional services:

- prove work;
- fund local goods;
- show governance;
- allocate locally;
- record contribution;
- route fees transparently.

## Product Narrative

> TIME Protocol does not ask a jurisdiction to abandon its system. It gives the jurisdiction a transparent, human-native economic layer it can adopt one module at a time.
