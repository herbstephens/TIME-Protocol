# TIME Protocol Reference Applications

## Purpose

Reference applications prove that TIME is not just a token.

They demonstrate that verified human time can become infrastructure for work, relationships, governance, jurisdictions, and parallel societies.

## 1. Governance Agent

**Category:** Governance / AI agent / local awareness

The Governance Agent maps the officials, laws, budgets, and institutions governing a verified human, then allows that human to allocate TIME toward or away from them.

Key primitives:

- one human, one agent;
- home jurisdiction;
- status-quo allocation;
- move TIME = vote;
- support and opposition staking;
- local opportunity discovery.

## 2. HumanBond

**Category:** Relationship infrastructure / two-person DAO

HumanBond uses World ID to verify two humans and establish an on-chain relationship bond.

Key primitives:

- two verified humans;
- soulbound Vow NFTs;
- daily TIME yield for time together;
- yearly Milestone NFTs;
- clean-exit divorce;
- relationship registry API.

HumanBond demonstrates that TIME can represent shared human time, not only wage labor.

## 3. marriagePROOF

**Category:** Early relationship DAO prototype

marriagePROOF is an earlier ETHGlobal reference app for on-chain marriage, joint treasury management, proof of marriage, and privacy-preserving registry access.

It should be treated as a predecessor to HumanBond.

## 4. Logos TIME Module

**Category:** Sovereignty / parallel society infrastructure

The Logos TIME Module demonstrates how TIME can plug into a sovereignty stack:

- Waku work agreements;
- payment-triggered minting;
- Work NFTs;
- birthright clock;
- privacy-preserving state;
- decentralized storage.

Canonical phrase:

> Payment for work is the mint event.

## 5. Parallel Society

**Category:** Operating system narrative

Parallel Society combines:

- World ID identity;
- Governance Agent awareness;
- TIME Protocol economy;
- Waku/Logos coordination;
- TIME-staked governance.

It is the umbrella product story for a human coordination OS.

## 6. Network State Integration

**Category:** State formation / legitimacy / treasury

TIME can serve network states by providing:

- census through verified humans;
- treasury via protocol fees;
- economic history through Work NFTs;
- governance through TIME allocation;
- inter-state settlement through clearinghouse architecture.

## 7. Liberland Pilot

**Category:** Jurisdictional implementation

The Liberland blueprint positions TIME as:

- citizenship identity layer;
- economic layer;
- governance layer;
- tax clearinghouse;
- human/corporate distinction mechanism.

It is useful as a detailed jurisdictional case study, even if not formally adopted.
