# Canon

This directory contains the narrative and intellectual context for TIME Protocol.

The canon is not the protocol specification.

It exists to explain why TIME Protocol matters, what historical problems it responds to, and how it fits into a broader theory of economic reset, information integrity, and human-centered coordination.

## Canon Files

| File | Purpose |
|---|---|
| `book-trilogy.md` | Explains the three-book arc |
| `the-great-reset-context.md` | Places TIME inside the reset thesis |
| `the-lie-factory-context.md` | Frames the information crisis |
| `the-lie-of-investing-context.md` | Frames the capital-allocation crisis |
| `narrative-boundaries.md` | Defines what belongs in protocol docs vs canon docs |

## Guiding Principle

Keep the protocol clean.

Let the canon carry the philosophy.

TIME Protocol should be legible to developers, economists, policymakers, and builders even if they have not read the books.

The canon should then deepen the case for why TIME is necessary.
