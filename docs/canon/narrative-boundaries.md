# Narrative Boundaries

## Purpose

This file defines how to keep TIME Protocol rigorous while still connecting it to the broader book trilogy and Great Reset narrative.

## What Belongs in Core Protocol Docs

Core protocol docs should include:

- definition of TIME;
- minting rules;
- proof of humanity;
- proof of time;
- proof of work;
- proof of payment;
- daily issuance caps;
- tokenomics;
- Work NFTs;
- governance allocation;
- privacy assumptions;
- implementation roadmap;
- contract architecture.

Core docs should be readable by a developer or economist without requiring belief in any particular political thesis.

## What Belongs in Canon Docs

Canon docs should include:

- why the protocol matters;
- critique of fiat stablecoins;
- critique of information systems;
- critique of abstract investing;
- reset narrative;
- civilization-level framing;
- book summaries;
- public speeches;
- philosophical arguments.

## What Belongs in Reference Application Docs

Reference app docs should include:

- HumanBond;
- VolunteerPROOF;
- Governance Agent;
- WorkProof;
- Land Commons;
- Network State integrations;
- jurisdictional pilots.

## What Should Be Avoided in Core Docs

Avoid putting the following directly into the core technical spec:

- long book excerpts;
- partisan claims;
- predictions stated as certainty;
- unsupported macroeconomic claims;
- apocalyptic language;
- speculative price targets;
- claims that TIME will replace the dollar on a fixed date;
- claims that TIME is absolutely stable in purchasing-power terms.

## Preferred Framing

Strong but disciplined:

> TIME Protocol is a human-time-denominated monetary and governance layer designed for a world where proof of humanity, local allocation, and verified work become central economic primitives.

Avoid:

> TIME will definitely replace the dollar by date X.

Use:

> TIME is designed as a credible alternative coordination layer if dollar-denominated systems, institutional legitimacy, or abstract capital allocation continue to lose trust.

## Why Boundaries Matter

The protocol wins credibility by being technically precise.

The canon wins attention by being narratively powerful.

Keep both.
