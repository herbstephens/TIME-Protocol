# Canon — The Book Trilogy

TIME Protocol is the technical implementation of a three-book intellectual project by Herb Stephens. The books are the diagnostic and prescriptive foundation from which the protocol's specific design choices derive.

**The books explain why the old system fails. TIME Protocol specifies the replacement coordination layer.**

These are complementary claims, not competing ones. Developers, investors, and protocol users do not need to have read the books to use or evaluate the protocol. The canon exists for those who want the philosophical depth.

## The Narrative Boundary

The core protocol documentation focuses exclusively on technical specifications: minting rules, proof of humanity, contract architecture, economic design. The canon documents house the narrative and philosophical context.

This separation is intentional: it allows the protocol to be evaluated on its technical and economic merits by audiences who may not share the books' broader civilizational diagnosis — while providing full intellectual depth for those who want it.

---

## The 2034 Schelling Point

January 1, 2034 is TIME Protocol's extended transition horizon — the coordination target at which the protocol aims to have achieved sufficient adoption to function as a meaningful alternative economic coordination layer.

This is a target, not a promise. The protocol's value does not depend on hitting a specific date. It depends on building working infrastructure that demonstrates superior economic properties at each stage of deployment.

**2030** is the aspirational launch horizon for full protocol readiness and stable ecosystem deployment.

Both horizons are background narrative for the current deployment phase (2026). Current focus: ETHGlobal Lisbon, SCF Build Award, Valley of the Commons pilot, Oslo Freedom Forum 2027.
