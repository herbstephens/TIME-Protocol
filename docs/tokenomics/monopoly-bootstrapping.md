# Monopoly Bootstrapping Analogy

## Summary

The Monopoly analogy is useful because it explains why a new economic system must place currency into every participant's hands before the system can function.

## The Problem

If a new monetary system launches and users begin with zero, then the first real power belongs to:

- people with outside capital;
- employers;
- investors;
- exchanges;
- insiders;
- liquidity providers.

That recreates the old system.

TIME Protocol should not make humans buy their way into a human-time economy.

## Monopoly

In Monopoly:

1. every player receives starting money;
2. the board defines the economic environment;
3. movement through time and space creates events;
4. passing Go provides recurring income;
5. players use currency to act.

Without starting money, there is no game.

## TIME Protocol Mapping

| Monopoly | TIME Protocol |
|---|---|
| Player | verified human |

| Passing Go | daily UBI / ongoing birthright TIME |
| Full circuit around board | passage of time |
| Properties | local opportunities, businesses, laws, governance objects |
| Rent | payment flows |

| Game rules | smart contracts |

| Player choice | TIME allocation |

## The Core Insight

A new system needs currency to circulate before it can express preference, trade, work, or governance.

Retroactive Birthright TIME gives every verified human the equivalent of starting money.

Ongoing Birthright TIME gives every verified human the equivalent of passing Go.

Work TIME gives every verified human the ability to earn by contributing.

## Important Difference

Monopoly currency is arbitrary game money.

TIME is not arbitrary.

TIME represents the human time that each player has already lived and continues to live.

## Narrative Use

This analogy should be used carefully.

Good use:

> Just as Monopoly cannot start without giving players money, a human-time economy cannot begin by leaving verified humans with zero TIME.

Avoid:

> TIME Protocol is like Monopoly.

The analogy explains bootstrapping. It should not define the protocol.
