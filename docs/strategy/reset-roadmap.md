# Reset Roadmap

## Summary

This roadmap translates The Great Reset narrative into TIME Protocol implementation phases.

The goal is to avoid making the repo depend on one dramatic date while still preserving the transition thesis.

## Horizon Language

Use two horizons:

```text
2030 = aspirational launch horizon
2034 = extended transition horizon
```

This resolves the current mixed date language.

## Phase 1 — Protocol Legibility

Make TIME understandable.

Deliverables:

- stablecoin thesis;
- tokenomics spec;
- proof-of-humanity model;
- proof-of-time model;
- Work Receipt model;
- World Chain deployment registry;
- reference app map.

## Phase 2 — Human Reference Apps

Prove that verified humans can use TIME.

Deliverables:

- HumanBond;
- VolunteerPROOF;
- WorkProof;
- Governance Agent MVP;
- local allocation dashboard.

## Phase 3 — Public Goods and Commons

Connect human time to shared resources.

Deliverables:

- Land Commons integration;
- CommonsDistributor;
- local public-goods pools;
- volunteer sponsorship;
- community treasury.

## Phase 4 — Shadow Democracy

Turn TIME into a governance preference layer.

Deliverables:

- status-quo allocation;
- support/oppose staking;
- quadratic weighting;
- jurisdictional mapping;
- official/law/budget registries;
- public dashboards.

## Phase 5 — Jurisdictional Pilots

Deploy TIME in real communities.

Candidates:

- DAO;
- nonprofit;
- city;
- network state;
- micronation;
- World Chain community;
- public-goods organization.

## Phase 6 — The Reset Layer

When enough pieces exist, TIME becomes credible as a transition layer:

- proof of humanity;
- wallet distribution;
- work-backed money;
- public-good dividends;
- governance preference;
- local allocation;
- reputation and economic history.

## Strategic Rule

Do not promise a global reset by date.

Build the infrastructure so that if a reset moment arrives, TIME is ready.
