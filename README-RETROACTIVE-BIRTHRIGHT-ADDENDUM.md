# Retroactive Birthright TIME Addendum

This addendum elevates retroactive birthright allocation to a core TIME Protocol primitive.

The central idea:

> Every verified human should be granted TIME at a rate of one unit per day since birth, as if the TIME Protocol had always existed.

This is not merely a token distribution mechanism. It is the protocol's founding act of recognition.

## Why This Matters

A new monetary system cannot begin from zero.

If a protocol asks humans to enter a new economy without native currency, the system recreates the old problem: early capital holders dominate, while ordinary people must first sell labor or buy in before they can participate.

TIME Protocol avoids this by recognizing that every human has already been living through time.

The protocol does not create human time. It recognizes it.

## Monopoly Analogy

In Monopoly, the game cannot start until every player receives starting money.

Then, as players pass Go, they receive additional money because a full trip around the board represents a completed cycle.

TIME Protocol has the same logic:

1. **Retroactive birthright allocation** gives every verified human starting currency.
2. **Daily UBI issuance** is the recurring pass-Go payment.
3. **Work minting** rewards verified contribution during the game.

The board is life.

The trip around the board is time.

The starting money is retroactive birthright TIME.

The pass-Go money is daily UBI.

## Canonical Rule

```text
retroactive_birthright_TIME = verified_days_alive × 1 TIME/day
```

Where:

```text
verified_days_alive = current_date - verified_birth_date
```

## Relationship to Daily Issuance

Retroactive birthright catches the human up to the present.

Daily birthright continues from that point forward.

```text
Initial claim: 1 TIME per day since birth
Ongoing claim: 1 TIME per day after verification
```

## Relationship to Work TIME

Retroactive birthright is not payment for labor.

It is recognition of human time lived.

Work TIME remains separate:

```text
Birthright TIME = recognition of lived human time
Work TIME = payment-backed minting for verified human work
```

## Recommended Token Categories

TIME Protocol should track at least three issuance categories:

| Category | Meaning |
|---|---|
| Retroactive Birthright TIME | one-time catch-up allocation since birth |
| Ongoing Birthright TIME | daily UBI after verification |
| Work TIME | payment-backed minting for verified work |

## Foundational Claim

> TIME Protocol does not begin when the smart contract is deployed. TIME begins when the human is born.
